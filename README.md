# Mech Suit (Forge 1.20.1, client-only)

Мех в стиле Titanfall из ~200 block_display (бетон) + шалкеры-коллизия. Видят все на сервере, мод нужен только тебе.
Ты сидишь в кабине (груди меха), креатив обязателен, нужен OP.

Клавиши: G (держать) - меню, Z (держать) - пушка, X - ракеты, C - рывок, R - удар.
Сборка: push -> Actions -> mechsuit-jar. Модель: src/main/resources/mech.json.
